# 0010. Баланс водителя: пополнения, переводы, акции

- Статус: принято владельцем продукта (B), 27 октября 2026.
- Основание: решения владельца 27.10.2026; REQ-LED-01…06, REQ-PAY-16 (долг водителя), ADR 0008, ADR 0009.

## Решения владельца

1. **Баланс водителя** (`DRIVER_PAYABLE` в журнале) пополняется:
   - картой из приложения водителя (WayForPay);
   - через терминал самообслуживания — первой сетью будет **EasyPay** (API владелец передаст позже; до этого — только контракт и поддельный адаптер);
   - вручную администратором (право, причина, аудит);
   - деньгами за поездки, оплаченные картой или бонусами пассажира (уже так: доля водителя в журнале);
   - бонусами по акции для водителей.
2. **Перевод водитель → водитель** части баланса. Ограничения задаются в настройках админки: максимум за один перевод, максимум за сутки, минимальный остаток после перевода, разрешены ли переводы вообще. Перевод — одна проводка в журнале, идемпотентно, обе стороны видят его в истории.
3. **Акции для водителей** создаёт администратор; их может быть несколько. Условия: период (длительность в днях), число выполненных заказов за период, дни недели, часы, тип оплаты заказа; награда — сумма бонусов на баланс. Пример: 50 заказов за 10 дней с 8 до 9, оплата картой — 100 на баланс.
4. **Повторяемость — настройка акции**: один раз за всё время акции или каждый период заново.
5. Награда начисляется за счёт службы: Дт `PROMO_EXPENSE` — Кт `DRIVER_PAYABLE`.

## Порядок работ

- A — пополнение администратором и история баланса водителя.
- B — переводы между водителями с ограничениями.
- C — акции для водителей.
- D — пополнение картой; E — EasyPay (после API).
