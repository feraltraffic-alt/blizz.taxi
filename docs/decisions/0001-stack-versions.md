# 0001. Матрица версий стека

- Статус: **предложено** (D), ждёт утверждения владельцем продукта и архитектором
- Дата: 26 октября 2026
- Основание: REQ-ENG-02, REQ-ENG-11; срез S-01

## Контекст

REQ-ENG-02 требует до начала реализации зафиксировать совместимую матрицу JDK / Spring / PostgreSQL / PostGIS / React Native / SDK с датой поддержки и выбирать версии проверкой совместимости, а не автоматически latest. REQ-ENG-11 требует закреплённых версий и lockfiles.

## Решение

### Backend

| Компонент | Версия | Почему |
|---|---|---|
| JDK | **25 (LTS)** | Текущий LTS, поддерживается Spring Boot 4.1 (линия 4.1 работает на Java 17–26). Java 21 из исходных материалов остаётся запасным вариантом |
| Spring Boot | **4.1.2** | Актуальный патч поддерживаемой линии 4.1 (вышел 23.10.2026); поддержка OSS линии 4.1 ориентировочно до 31.07.2027. Линия 4.0 заканчивает OSS-поддержку 31.12.2026 |
| Spring Modulith | **2.1.x** (2.1.1) | Линия 2.1 вышла вместе со Spring Boot 4.1. Используется для проверки границ модулей (REQ-ENG-04) и как кандидат outbox (REQ-ENG-05) |
| Flyway, Hibernate, драйвер PostgreSQL, Testcontainers | Версии из BOM Spring Boot 4.1.2 | Не закрепляем отдельно, чтобы не ломать согласованность BOM |
| Maven | 3.9.x | Сборка; Maven Wrapper добавляется вместе с CI |

### Данные и инфраструктура

| Компонент | Версия | Почему |
|---|---|---|
| PostgreSQL | **18** | Текущая основная версия |
| PostGIS | **3.6** | Поддерживает PostgreSQL 18 |
| Расширения БД | `postgis`, `pg_trgm` | Создаются миграциями Flyway; база инстанса (в том числе управляемая) должна разрешать их установку пользователю миграций. `pg_trgm` — поиск собственных адресов (REQ-GEO-13) |
| Redis | **8.x** | Предварительный подбор кандидатов и GEO (REQ-DSP-02). Альтернатива — Valkey (совместимый форк под BSD-лицензией); выбрать до production с учётом лицензии |

### Клиенты

| Компонент | Версия | Почему |
|---|---|---|
| Node.js | **24 LTS** | Сборка web и mobile |
| React | **19.3** | Совпадает с версией, на которой работает Expo SDK 58 |
| Vite | **8.x** | Сборка web-приложений |
| TypeScript | Уточнить при каркасе web | Вышла 7.0 (новый нативный компилятор); совместимость с инструментами проверить отдельно |
| Expo SDK | **58** | React Native 0.88, React 19.3; iOS 16.4+, Android 7+ |
| React Native | **0.88** | Версия Expo SDK 58 |

Expo — вариант реализации, а не продуктовое требование (REQ-ENG-01). Фоновую геолокацию проверяем только на dev build и реальных устройствах, не в Expo Go (REQ-DRV-14, REQ-UX-04). Окончательная матрица устройств и SDK — Q-17.

## Последствия

- Все версии закрепляются в `pom.xml`, `package.json` и lockfiles; обновление — отдельный коммит с прогоном проверок.
- Пересмотр матрицы: при выходе новой LTS-линии Spring Boot и перед каждым production-релизом.
- Пункты «уточнить» закрываются до каркаса соответствующего приложения.
