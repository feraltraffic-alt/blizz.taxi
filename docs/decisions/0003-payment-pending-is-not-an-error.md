# 0003. «Оплата в процессе» — не ошибка

- Статус: принято (D)
- Дата: 26 октября 2026
- Основание: раздел 22.1 (REQ-API-11), 22.4, вопрос из PR #3 / issue #1

## Проблема

В `ErrorCode` коды `PAYMENT_PENDING` и `PAYMENT_UNKNOWN` имели HTTP 202, а схема `Problem` допускает только 400–599. Исключение с таким кодом давало бы «ошибку» со статусом успеха.

## Решение

- Команда, чья собственная оплата ещё не завершена, отвечает **202** с телом `AcceptedOperation` (`operation_id`, `status_url`) — это обычный результат, не исключение (REQ-API-11).
- Как ошибка (`Problem`) эти коды возвращаются только со статусом **409**: действие конфликтует с оплатой, результат которой ещё не известен (например, повторная попытка заплатить). Клиент не платит второй раз, а проверяет статус операции.
- `ErrorCode.PAYMENT_PENDING` и `PAYMENT_UNKNOWN` переведены на 409; тест обработчика ошибок проверяет все коды без исключений.
