# ADR 0017. Owner answers of 03.11.2026: map tiles, the driver's position for the rider, the admin live map, tariffs

Date: 03.11.2026. Status: accepted (the owner's answers in the lead's session).

## 1. Map tiles: OpenStreetMap

The admin panel and the operator panel draw their maps with Leaflet on OpenStreetMap tiles
(`https://tile.openstreetmap.org`), as ADR 0012 (Q-08) planned.
- The OSM tile usage policy applies: the attribution is shown, and the zoom stays within what the server serves.
- Each panel's CSP allows images from that host only.
- If the load grows past what the policy allows, an own or a paid tile server replaces it, as ADR 0012 already says.

Done in #465, #467, #468, #470, #472 and #475.

## 2. The rider sees the driver's position

The owner: "Every app shows it (Uber, Bolt, Uklon). Why not ours?"
- While a driver is assigned to the rider's order and on the way, waiting, or on the trip, the rider's app shows the
  driver's last known position on a map.
- Before an assignment, after the trip ends, and for any other order, no position is given.
- What the rider receives is only the position the server already holds for dispatch (REQ-PRV-02: shown, not stored anew).

## 3. The admin panel has its own live map

REQ-ADM-01 lists a live map among the admin sections. The admin API gets the same live board the operator panel
has: `GET /api/admin/v1/drivers/live`, with the same `orders.view` check per city.

## 4. The tariffs API: not now

#30 stays deferred. A pilot's tariff is still inserted by SQL.
