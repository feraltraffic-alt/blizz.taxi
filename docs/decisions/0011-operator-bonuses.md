# 0011. Бонусы операторов

- Статус: принято владельцем продукта (B), 27 октября 2026.
- Основание: решения владельца 27.10.2026; ADR 0007 (причины отмены).

## Решения владельца

1. У каждого оператора — **бонусный счёт** (баллы, не деньги и не журнал службы). Оператор сам его не пополняет.
2. **+m** баллов за каждый заказ, который оператор **оформил и который выполнен** (FULFILLED). Заказ засчитывается тому, кто его оформил, даже если дальше с ним работали другие.
3. **−g** баллов за заказ, **отменённый по вине оператора**: в справочнике причин отмены для сотрудников у причины есть отметка «по вине оператора» (например, «Ошибка оператора»). Штраф получает тот, кто оформил заказ.
4. **Настройки в админке:** m, g, учитывать ли отмены по вине оператора, **день месяца обнуления** (например, 15-е). При обнулении итог периода сохраняется (кто сколько набрал), счёт начинается с нуля.
5. **Особые правила по времени** (например, часы пик): дни недели и часы со своими m и g; если правило не подходит — действуют общие m и g. Время — по часовому поясу города заказа, момент — оформление заказа.
6. Каждое начисление и списание — запись в истории счёта оператора с заказом и правилом, по которому оно сделано. Пример: Анна оформила 700 выполненных заказов, 10 отменены по её вине, m = 1, g = 10 → 600.
